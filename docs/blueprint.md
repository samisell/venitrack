# **App Name**: VeniTrack

## Core Features:

- Login: Email and User ID login form with redirect to Leads Dashboard upon success.
- Leads Dashboard: Display application, admission, and visa statuses, outstanding payments, and assigned counselor.
- Application Stages Tracker: A stepper to visualize the journey. Lead Received > Document Submitted > School Application Sent > Offer Received > Admission Accepted > Visa Processing > Travel Preparation
- Profile Information: Read-only display of personal details.
- Document Management: UI to upload documents with status tracking and replace functionality.
- Payments Section: Display payment history and action buttons to 'Pay Now'.
- Support & Messaging: Chat-style interface to communicate with counselor or support.

## Style Guidelines:

- Primary color: #2E9CCA, a professional blue to promote trust and competence. This reflects the reliability Venihost offers in guiding students through their study abroad journey.
- Background color: #F0F8FF, a very light blue provides a calm and unobtrusive backdrop.
- Accent color: #CA3B2E, a muted red used sparingly for critical actions or notifications.
- Body font: 'PT Sans', a humanist sans-serif for readability and modern appeal.
- Headline font: 'Playfair', a modern serif for elegance and a high-end feel.
- Use icons to visually represent document types and application stages.
- Modern SaaS-style layout with a sidebar for main navigation.
- Subtle transitions and loading animations to enhance user experience.
